# Shared example assets

`placeholder.png` — a small self-contained gray Material-surface placeholder used
in Code Connect example image slots (card media, search-view result media) where
the Figma M3 kit shows a placeholder image. `placeholder.datauri.txt` is the same
image as a `data:` URI for inline embedding in emitted examples.

Swap in the real Figma placeholder (export the kit's shared image node) if an
exact-match asset is preferred; the data-URI keeps examples self-contained.
