# Security Policy

`elm-review-cem` is a build-time developer tool — a set of `elm-review` lint
rules. It runs only during local development / CI and ships no runtime code to
end users, so its security surface is minimal.

## Reporting a vulnerability

Please report any security concern **privately**, not through a public issue —
use GitHub's
[private vulnerability reporting](https://github.com/jackhp95/elm-review-cem/security/advisories/new)
or contact the maintainer [@jackhp95](https://github.com/jackhp95). Please allow a
reasonable time for a fix before any public disclosure.
