## 6. The coverage ceiling (critical domain fact)
The auto-matcher bound 36; manual bridging + confirms reached 49. **Composed / stateful / hidden
components cannot be pixel-*gated*** — their Figma variants carry arbitrary demo content (avatars,
lorem ipsum, specific labels), so a clean binding never pixel-matches. Those are banked as
`gate:"example-verified"` (NOT `"approved"`) and force-published. So adding coverage for composed
components = author correspondence + example children + confirm as example-verified; it does NOT
require passing the pixel gate. See `docs/coverage-and-gaps.md`.
