# elm-typed-svg

Type-safe native **SVG** for Elm — the `TypedSvg` brand, generated by
[`elm-cem`](../../../../../pipeline/elm-cem) from two committed inputs, exactly
like the [`elm-typed-html`](../../../../html/generated/package/elm-typed-html)
native-HTML brand:

- `manifest/svg.cem.json` — a hand-authored Custom Elements Manifest of the SVG
  element vocabulary (element-specific geometry/structural attributes), authored
  from the W3C SVG spec + MDN, cross-checked against `elm/svg`.
- `../../../inputs/config.json` — the phantom-typing config (`_brand`,
  `_namespace`, `_globals`, per-element `home`/`admits`).

Every module under `src/` is emitted; there are **zero post-codegen tweaks**, and
that contract is enforced by the regen-diff gate (`scripts/regen-diff-gate.sh`).

## What makes SVG a distinct kind of brand

An SVG element is not an HTML element. A `<circle>` created with
`document.createElement("circle")` (the HTML namespace) does **not render** — the
DOM node must be created with
`document.createElementNS("http://www.w3.org/2000/svg", "circle")`. The
generator learns this from the one SVG-specific config key, `_namespace`, and
emits every element constructor as `Ir.nodeNS "<uri>" "<tag>"` instead of
`Ir.node "<tag>"`. That routes through `VirtualDom.nodeNS` → `createElementNS`.

`Ir.nodeNS` / `keyedNodeNS` / `attributeNS` are the additive that
`jackhp95/elm-virtual-dom-intermediate-representation` gained in **1.1.0** — the
IR gap that had blocked an SVG brand. Everything else (phantom rows, the
`class`/`style` merge, keyed diffing, the shared substrate that lets an `<svg>`
nest inside `TypedHtml`/`M3e` content) is inherited unchanged from the IR.

## Shape

- `TypedSvg` — the barrel: every element constructor (`svg`, `g`, `rect`,
  `circle`, `path`, `text_`, `linearGradient`, `stop`, …) plus `text` (the shared
  text-content atom) and `toHtml` (the render boundary). Note `text_` for the
  `<text>` element, mirroring `elm/svg` — the unsuffixed `text` is the content
  atom.
- `TypedSvg.Element.*` — the strict per-group modules (Shape, Structure, Text,
  Paint, Clip, Descriptive, Image) with tightened child-slot rows.
- `TypedSvg.Attributes` — element-specific (`cx`, `viewBox`, `d`, …) and open-row
  presentation setters (`fill`, `stroke`, `strokeWidth`, …). Presentation
  attributes are open-row, so they compose onto any element by unification —
  faithful to SVG, where presentation properties are near-universal.
- `TypedSvg.Values` — enum tokens (`round`, `middle`, `nonzero`, …) for the typed
  enum attributes (`stroke-linecap`, `text-anchor`, `fill-rule`, …).
- `TypedSvg.Events`, `TypedSvg.Kind`, `TypedSvg.Review.Facts` — as every brand.

## Scope — audited against SVG 2

The element and attribute vocabulary is **audited against the W3C SVG 2 spec**
and that coverage is **mechanically gated** — a spec-index bump or a package
regen that opens an un-annotated gap fails CI. See
[`docs/svg-audit/`](../../../../../docs/svg-audit/) for the full audit
(`2026-08-21-svg-coverage-audit.md`), the machine-readable spec vocabulary
(`spec-index.json`, 69 elements), and the deferral/non-goal ledger
(`coverage-map.json`, enforced by `tools/check-svg-spec-coverage.mjs`).

**In scope (SVG 2 static render surface):** the classic shapes, structure,
gradients, paint, clip/mask/marker, text, `image`, plus `foreignObject` (the
bridge back into `TypedHtml`), `view`, `metadata`, the conditional-processing
selectors on `switch`, and the **full 26-element filter family** (`filter` +
every `fe*` primitive, with typed filter enums). Presentation properties are
modeled with type fidelity: **30 typed enum value-domains** (up from 6),
covering the baseline, rendering-hint, text-layout, and filter families.

**Documented deferrals / non-goals:**

- **SMIL animation** (`animate*`, `set`, `mpath`, `discard`) — deferred
  (`smil-deferred`): a distinct declarative-timeline model with perennial
  Chromium deprecation risk; a modeled seam is left for a later pass.
- **`xlink:` namespace** (`xlink:href`, `xlink:title`) — non-goal
  (`xlink-legacy`): superseded by the bare `href` attribute, which **is**
  modeled — the SVG-2-preferred form.
- **Path-data DSL** — non-goal (`path-data-non-goal`): the `d` attribute is
  modeled as a `String`; a fully-typed path-command DSL is a large surface and a
  real ergonomic loss.
- **HTML-embed elements in the SVG namespace** (`audio`/`canvas`/`iframe`/
  `video`), raw-text carriers (`script`/`style`), `unknown`, and the deprecated
  `zoomAndPan` — non-goals, each bucketed in `coverage-map.json`.
- **ARIA and events** are handled by design through a future `Aria` surface and
  `TypedSvg.Events` respectively, not as attribute setters.

```
npm run gen         # regenerate src/ from manifest + config
npm run check       # format + compile (verify/) + regen-diff gate
npm test            # render assertions (tests/src/RenderTest.elm)
```
